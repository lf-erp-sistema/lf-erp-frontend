# Guia simples — registrar uma venda no PDV

Use este guia para cada venda feita na loja.

> Regra importante: só clique em **Finalizar venda** depois de conferir os produtos, a quantidade e a forma de pagamento.

## Antes de começar

1. Entre no sistema com seu usuário.
2. No menu à esquerda, clique em **PDV**.
3. Se o sistema avisar que o caixa está fechado, abra o caixa antes de vender ou peça ajuda.
4. Para começar uma venda nova, clique em **+ Nova venda**.

## Registrar os produtos

1. Na busca de produtos, digite:

   - o nome do produto; ou
   - o código de barras; ou
   - o código do produto.

2. Clique no produto correto para adicioná-lo ao carrinho.
3. Se o cliente levar mais de uma unidade, altere a quantidade no carrinho.
4. Repita o processo para todos os produtos da venda.
5. Confira o valor total mostrado no canto inferior direito.

## Cliente

Na maioria das vendas, não é obrigatório informar cliente.

- Se não precisar cadastrar o cliente, deixe como **Consumidor final**.
- Se precisar emitir venda para uma pessoa cadastrada, vá em **Cliente e pagamento**, pesquise o nome e selecione a pessoa correta.
- Nunca cadastre outro cliente só porque não encontrou o nome de imediato; pesquise primeiro.

## Receber o pagamento

1. Vá para **Cliente e pagamento**.
2. Escolha a forma correta:

   - **Dinheiro**
   - **Pix**
   - **Cartão de Débito**
   - **Cartão de Crédito**
   - **Promissória**, quando a venda for para pagar depois

3. Confira o valor informado.

### Quando o cliente paga em dinheiro

- Digite o valor recebido.
- O sistema mostra o troco quando for necessário.
- Confirme se o troco mostrado confere antes de finalizar.

### Quando o pagamento for dividido

Exemplo: uma parte em dinheiro e outra no Pix.

1. Clique em **Adicionar forma**.
2. Informe cada forma e o valor pago em cada uma.
3. A soma precisa ser igual ao total da venda.

## Finalizar a venda

1. Confira mais uma vez:

   - produtos;
   - quantidades;
   - valor total;
   - pagamento;
   - cliente, se houver.

2. Clique em **✓ Finalizar venda**.
3. Espere a mensagem de sucesso.
4. Só então entregue o comprovante ou conclua o atendimento.

## Se cometer um erro antes de finalizar

- Produto errado: remova o produto do carrinho.
- Quantidade errada: ajuste a quantidade.
- Pagamento errado: volte em **Cliente e pagamento** e corrija antes de finalizar.
- Se precisar atender outro cliente antes de terminar: use **Em espera**.

## Se cometer um erro depois de finalizar

Não faça uma nova venda para “corrigir”. Anote o número/horário da venda e peça ajuda antes de mexer no sistema.

## Cuidados importantes

- Cada venda baixará o estoque automaticamente.
- Não finalize duas vezes se a tela estiver carregando. Espere a mensagem do sistema.
- Se a internet cair ou aparecer mensagem vermelha, não tente repetir a venda várias vezes. Tire foto da tela e peça ajuda.
- Sempre confira se o valor no cartão, Pix ou dinheiro é o mesmo valor registrado no sistema.
