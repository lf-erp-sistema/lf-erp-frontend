Estoque e
produtos

Guia simples para cadastrar produtos e conferir quantidades.

Antes de cadastrar: pesquise o produto. Assim evitamos cadastrar o mesmo item duas vezes.

Use este guia quando:

  • chegar mercadoria nova;
  • for cadastrar um produto;
  • precisar corrigir uma quantidade.

1. Cadastrar produto novo

  1. Entre no sistema com seu usuário.
  2. No menu esquerdo, clique em Cadastros → Produtos.
  3. Clique em + Novo produto.
  4. Preencha os campos principais:
  • Nome: nome fácil de entender.
  • Preço de venda: quanto o cliente paga.
  • Custo: quanto a loja pagou.
  • Estoque inicial: quantidade que chegou.
  • Estoque mínimo: sugestão de 2 ou 3 unidades.
  • Código de barras: preencha se existir na embalagem.
  1. Clique em Salvar produto.
  2. Espere a mensagem de sucesso antes de fechar a tela.
Atenção: preço de venda é o valor cobrado do cliente. Não coloque o custo nesse campo.

2. Corrigir quantidade

  1. Vá em Cadastros → Produtos.
  2. Pesquise o produto pelo nome ou código de barras.
  3. Clique no botão ± ao lado da quantidade.
  4. Digite a quantidade que existe de verdade na loja.
  5. Confirme e espere a mensagem “Estoque atualizado”.
Exemplo: se o sistema mostra 3, mas você contou 8, digite 8.

3. Conferir o estoque

  1. Abra Movimentações → Estoque.
  2. Pesquise o produto.
  3. Confira se a quantidade mostrada é a mesma que foi contada.
Checklist antes de salvar
□ Produto não está duplicado
□ Nome está correto
□ Preço de venda está correto
□ Quantidade foi conferida
Lembrete: as vendas feitas no PDV baixam o estoque automaticamente. Não é preciso baixar manualmente após cada venda.
Se aparecer mensagem vermelha: pare, tire uma foto da tela e envie para quem cuida do sistema. Não tente criar outro produto para resolver.
